When a task arrives:

1. Match the user's request to one or more categories below.
2. The category lists which rooms across the project are relevant.
3. Combined with the wing scope (which modules are touched), this gives you the minimum doc set to load.

Categories are derived from actual room names found across all wings. If no wings have rooms yet, this file is empty until `/init` runs.
